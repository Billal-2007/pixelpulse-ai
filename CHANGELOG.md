# Changelog

All notable changes to PixelPulse AI will be documented in this file.

## [1.2.0] - 2026-10-31
### Added
- Integrated 5 Free APIs support (Pexels, Pixabay, Openverse, Unsplash, FreeSound).
- Added dedicated Blog page (`blog.html`) and Contact form (`contact.html`) with Formspree integration.
- Added custom 404 error page, Terms & Conditions, and Privacy Policy pages.
- Enhanced PWA service worker offline capabilities with `offline.html`.

## [1.1.0] - 2026-10-15
### Added
- Firebase Analytics visitor tracking integration.
- Admin dashboard (`admin.html`) with secure authentication.
- Bilingual language toggle (English & Bengali).

## [1.0.0] - 2026-10-01
### Added
- Initial release of PixelPulse AI media downloader framework.
- Core 4-episode wildlife video production guides.
