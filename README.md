# PixelPulse AI 🚀

An advanced, modular, and free-tier 4K/8K media downloader and AI prompt generator web application built with HTML, CSS, JavaScript, and Firebase.

## ✨ Features
* **Multi-Source Media Fetcher:** Download copyright-free videos, music, and photos from top free platforms (Pexels, Pixabay, etc.).
* **AI Prompt Box & Assistant:** Open-source AI integration with IP-based rate limiting.
* **Secure Admin Panel (`/admin`):** Manage traffic statistics, 24-hour auto-reset visitor counters, lifetime subtotal counts, and custom ad codes.
* **PWA & Mobile App Support:** Installable as a Progressive Web App (PWA) with a dedicated APK download option.
* **Fully Modular Structure:** Organized into separate component files for easy maintenance and updates.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript (GitHub Pages Hosting)
* **Backend & Analytics:** Firebase Firestore & Authentication
* **Security & CDN:** Cloudflare
* **APIs:** Pexels, Pixabay, and Open-Source AI APIs
